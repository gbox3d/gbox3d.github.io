Class Community Helper

BAND 인증 콜백

대학 수업용 커뮤니티 활동 보조 도구의 사용자 인증 결과를 전달받는 전용 페이지입니다.

인증 대기 중입니다

애플리케이션에서 인증을 시작하면 완료 후 이 페이지로 돌아옵니다.

교육 목적과 이용 범위

  • 교수 본인 계정으로 운영하는 수업용 BAND에서 사용하는 비상업적 교육용 도구입니다.
  • API 연동 및 사용자 승인형 커뮤니티 도구를 대학 수업에서 실습하기 위한 목적입니다.
  • 수업 안내와 학습자료 게시글·댓글은 사용자가 직접 검토하고 승인한 경우에만 등록합니다.
  • 무인 자동 실행, 대량 게시, 광고 목적으로 사용하지 않습니다.

개인정보 및 보안

  • 이 정적 페이지는 인증 결과를 별도로 저장하거나 제3자에게 전송하지 않습니다.
  • 인증 코드와 토큰은 화면에 표시하지 않습니다.
이 페이지는 BAND 공식 서비스가 아니며, BAND와의 제휴 관계를 표시하거나 암시하지 않습니다.
